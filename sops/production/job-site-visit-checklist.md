# Job Site Visit Checklist

**Owner:** CEM (fills out on each visit)

**Applies to:** Every daily site visit during an active project.

**Related:** `daily-site-visit.md`

## Purpose

A repeatable, honest assessment tool used on every job site visit. Each
category is scored per side of the house: check mark if it's being done,
X if it's not. Patterns of X's across visits or crews trigger a review.

## How To Use

1. Print or pull up the checklist on your phone/Company Cam.
2. Walk each side of the house (1–4).
3. For each item in each category, mark ✓ or X on every side.
4. For any X, address it with the crew leader on the spot.
5. Store the completed checklist with the project record.

## Checklist

| Category | Items | Side 1 | Side 2 | Side 3 | Side 4 |
|---|---|---|---|---|---|
| **Prep** | 1. Scraping, sanding, priming. 2. Caulking cracks. 3. Right paint and products being used? |  |  |  |  |
| **Cleanliness** | 1. Drips or overspray anywhere? 2. Sloppiness on lights, brick, or stone? 3. Paint in the grass? Paint chips picked up from prep? |  |  |  |  |
| **Trash & Jobsite Cleanliness** | 1. Trash in one place and bagged? 2. Tape, masking, or empty paint lying around? 3. Cigarette butts, Gatorades? 4. Tools scattered around the house? |  |  |  |  |
| **Touch-Ups** | 1. Work being done right the first time? 2. Prep done *before* painting? 3. Spraying fully done *before* trim goes on? 4. Covering properly? 5. Clean lines? |  |  |  |  |
| **Branding** | 1. Lawn sign up? 2. Jobsite presentable? 3. Paint job looks great? 4. Trucks/cars parked appropriately? 5. Any other company being represented? 6. Flyers dropped on nearby homes? 7. Photo taken and sent to marketing. |  |  |  |  |
| **Customer & Contractor Interaction** | 1. If customer home, say hi and build rapport. 2. Are they happy? 3. If they aren't home, give them a call. 4. Are the painters happy? 5. Anything we can get anyone? |  |  |  |  |
